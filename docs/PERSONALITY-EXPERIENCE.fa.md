# تحویل بازطراحی شخصیت و استوری — ۲۴ اکتبر ۲۰۲۶

## وضعیت بررسی‌شده و تصمیم اجرایی

پروژهٔ موجود ASP.NET Core 8 / Razor Pages، با لایه‌های Domain، Application، Infrastructure و Web و EF Core / SQL Server است. موتور DiscoveryEngine، تصمیم AnalysisDecision، کنترل مالکیت DiscoveryService، تحلیل KnowledgeEngine، فونت محلی وزیرمتن و خروجی Canvas از قبل وجود داشتند. مشکل، نمایش هم‌زمان دادهٔ خام، طیف‌ها، تنظیمات و کارت‌های متعدد بود. همان زیرساخت استفاده شد؛ جدول، پکیج، سرویس خارجی یا سیستم احراز هویت تازه‌ای اضافه نشده است.

صفحهٔ `/Ui/Discover` اکنون یک معرفی یکپارچه دارد: لقب مبتنی بر قواعد واقعی، معرفی کوتاه، حداکثر شش فکت از دسته‌های متفاوت، بازخورد و مسیر استوری. انتخاب‌های خام، درصد طیف‌ها و MBTI از این صفحه برداشته شده‌اند؛ محاسبات داخلی حفظ شده‌اند. تنظیمات، MBTI، مقایسهٔ دوطرفه، ویرایش پاسخ‌ها و مدیریت لینک عمومی در `/Ui/Discover/Settings` قرار دارند. مسیر قدیمی `/Ui/Discover/Facts` به صفحهٔ یکپارچه هدایت می‌شود؛ POSTهای قبلی آن همچنان کنترل دسترسی دارند.

صفحهٔ مقایسه نیز به جمع‌بندی کوتاهِ اشتراک و تفاوت تبدیل شده و جدول انتخاب‌های خام را نمایش نمی‌دهد؛ داده و رضایت دوطرفهٔ قبلی در سرویس حفظ شده‌اند.

## قابلیت‌های آماده

- فکت‌های کوتاه و صمیمی با متن‌های متنوع و انتخاب تکرارپذیر؛ بدون نسبت‌دادن هنرمند، علاقه یا شخصیتِ پرسیده‌نشده. برای برداشت اجتماعی، برنامه‌ریزی و تجربهٔ تازه حداقل سه پاسخ مستقل لازم است. بدون شاهد، جملهٔ پرکننده تولید نمی‌شود.
- بازخورد «درسته / شبیه من نیست» بدون بارگذاری دوباره، با نمایش وضعیت و امکان تغییر نظر؛ فرم معمولی هم بدون JavaScript کار می‌کند. مالک از نشست شناسایی می‌شود، CSRF بررسی می‌شود و بازخورد به ۸۰ درخواست در دقیقه برای حساب محدود است.
- کلید مرکب موجود `(UserId, ResultKey)` یک تصمیم برای هر فکت نگه می‌دارد. تکرار همان نظر، Revision، زمان، نسخهٔ پروفایل یا لینک انتشار را عوض نمی‌کند. تغییر واقعی نظر، انتشار قبلی آن فکت را لغو می‌کند. فکت ردشده مبنای لقب یا استوری نیست.
- پیش‌نمایش `/Ui/Discover/Story` با انتخاب حداکثر چهار فکت تأییدشده؛ انتخاب خالی، خالی می‌ماند. فکت حساس، ردشده، تأییدنشده یا شناسهٔ نامرتبط وارد استوری نمی‌شود. لقب استوری نیز فقط از همین مجموعه ساخته می‌شود. هیچ استوری خودکار عمومی نمی‌شود.
- پیش‌نمایش `/Ui/Game/Story` از جمع‌بندی همین دور بازی؛ حداقل دو سؤال عمومیِ شناخته‌شده که هرکدام حداقل پنج شرکت‌کنندهٔ تکمیل‌شده و متمایز با پاسخ معتبر داشته باشند. سؤال ناشناخته، حساس، اختصاصی MBTI، متن آزاد، پاسخ ردشده، گزینهٔ نامعتبر و timeout کنار گذاشته می‌شوند.
- استوری دوستان شامل روایت کلی و دو تا سه فکت تجمیعی است. نام، شناسه، گزینهٔ انتخابی، متن سؤال یا پاسخ خصوصی دوستان در DTO رندر وجود ندارد. تعداد نمونه و دامنهٔ نتیجه مشخص‌اند. این جمع‌بندی میزان موفقیت در حدس را نشان می‌دهد، نه کیفیت رابطه یا سلیقهٔ خود دوستان.
- خروجی مستقل PNG با ابعاد ۱۰۸۰×۱۹۲۰، عنوان، معرفی، نشانه‌های بصری، فکت‌ها، جملهٔ مثبت و هویت برنامه. اشتراک فایل با Web Share API و در نبود پشتیبانی، دانلود تصویر. فونت از پروژه بارگذاری می‌شود؛ تصویر اختصاصی ضروری نیست.

## قرارداد فکت و اتصال تصویر آینده

AnalysisFact موجود با `CategoryKey`، `VisualKey`، `Emoji`، `Certainty`، `RuleKey` و `StoryText` تکمیل شده است. شناسه، تصمیم، امکان انتشار و شواهد قبلی نیز حفظ شده‌اند. CategoryKey و Certainty در JSON نام ثابت دارند؛ UI اصطلاح فنی یا عدد اطمینان روان‌شناختی نمایش نمی‌دهد. StoryContent / StoryFact فقط خروجی مناسب رندر را حمل می‌کنند و حاوی شواهد خام نیستند.

نسخهٔ متن `personality-copy-v1` است. شناسهٔ فکت به قاعده، نسخهٔ متن و نسخه/Revision شواهد وابسته است. با تغییر پاسخ یا معنای متن، تأیید قبلی خودکار به خروجی تازه منتقل نمی‌شود. متن‌های قدیمیِ گزارش‌گونه شناسهٔ دیگری داشتند؛ تأییدهایشان حذف نشده‌اند، ولی برای فکت‌های جدید باید دوباره نظر داد و لینک‌های آن متن‌های قدیمی ممکن است دیگر معتبر نباشند. امتیازها، بازی‌ها، پاسخ‌ها و آرشیوها تغییر نکرده‌اند.

رجیستری اختیاری `FriendShip.web/wwwroot/friendship/visual-assets.json` فعلاً `{}` است. وقتی تصاویر آماده شدند، فایل را به `/images/` پروژه اضافه کنید و مسیرش را با کلید مربوط نگاشت کنید:

```json
{
  "music.headphones": "/images/facts/music.webp",
  "animals.cat": "/images/facts/cat.webp",
  "gaming.controller": "/images/facts/gaming.webp"
}
```

این نمونهٔ قرارداد است؛ مسیرهای نمونه در رجیستری واقعی ثبت نشده‌اند. کلیدهای فعلی:

| مضمون | کلیدهای تصویر |
| --- | --- |
| موسیقی، بازی، فیلم، کتاب | `music.headphones`، `gaming.controller`، `film.screen`، `books.stack` |
| حیوانات | `animals.cat`، `animals.dog` |
| سفر و طبیعت | `travel.suitcase`، `travel.nature` |
| غذا، ورزش، استایل | `food.pizza`، `sport.ball`، `style.shirt` |
| جمع و خلوت | `social.moon`، `social.party`، `social.balance` |
| برنامه و تجربه | `planning.calendar`، `adventure.rocket`، `lifestyle.home` |
| جمع‌بندی و جایگزین | `social.detective`، `social.spark`، `spark` |

سرور فایل تصویری انتخاب نمی‌کند. فرانت فقط مسیر هم‌مبدأ در `/images/` را می‌پذیرد. فایل ناموجود، رجیستری نامعتبر یا تصویر بارگذاری‌نشده به ایموجی برمی‌گردد؛ همان کلیدها در صفحه، پیش‌نمایش و Canvas استفاده می‌شوند. تصویر پس‌زمینه‌شفاف و کم‌حجم برای این فضا مناسب است.

مدل EF و Migration جدیدی لازم نشد. تصمیم‌ها در جدول موجود ذخیره می‌شوند؛ روایت و استوری هنگام درخواست محاسبه می‌شوند و ذخیرهٔ مشتق‌شدهٔ موازی ندارند. تنظیم و راه‌اندازی قبلی معتبر است.

## اجرا و نتیجهٔ اعتبارسنجی

```powershell
dotnet run --project FriendShip.web/FriendShip.Web.csproj --configuration Release --launch-profile https
dotnet test FriendShip.slnx --configuration Release
node scripts/check-frontend.cjs
node scripts/check-story-export.cjs
dotnet ef migrations has-pending-model-changes --project FriendShip.Infrastructure --startup-project FriendShip.web --configuration Release
```

در اجرای ۲۴ اکتبر ۲۰۲۶: **۳۹ تست .NET موفق، صفر شکست و صفر ردشده**، شامل ارتقای واقعی SQL Server روی دیتابیس تصادفیِ مختص تست و حفظ امتیاز قدیمی. آزمون‌ها انتخاب فکت، منشأ و حداقل شواهد، حیوان واقعی، لقب ترکیبی، استوری تأییدشده، بازخورد تکراری و تغییر نظر، CSRF، عدم دسترسی حساب دیگر، حذف اطلاعات فردی از JSON/HTML و حداقل نمونهٔ استوری دوستان را پوشش می‌دهند. EF تغییر مدل بدون Migration گزارش نکرد. دو هشدار قدیمی CS8981 برای نام migration اولیه باقی‌اند.

بررسی CSS و syntax پنج اسکریپت موفق بود. تست JavaScript واقعی صادرکننده در محیط شبیه‌سازی‌شده، ابعاد و محدوده‌های عمودی متن، چهار فکت، اشتراک فایل، عدم ارسال نشانی خصوصی، شکست فونت، رجیستری خراب، ممنوعیت تصویر خارجی و جایگزینی ایموجی را بررسی کرد.

نسخهٔ Release روی `https://localhost:7238` اجرا شد. بررسی HTTP با اعتبارسنجی عادی گواهی، پاسخ ۲۰۰ برای شروع، CSS، اسکریپت استوری، رجیستری و فونت محلی و پاسخ ۳۰۲ ورود برای صفحات شخصیت و هر دو استوری بدون نشست دریافت کرد. تست حساب‌ها و ثبت بازخورد روی دیتابیس مستقل آزمون انجام شد؛ برای این بررسی HTTP، پاسخ نمایشی یا کاربر آزمایشی به دیتابیس اصلی اضافه نشد.

طبق انتخاب قبلی کاربر مرورگر اجرا نشد. آزمون صادرکننده جای رندر واقعی نیست: ظاهر در موبایل، شکل نهایی حروف فارسی/ایموجی در PNG و اشتراک فایل روی دستگاه واقعی هنوز نیازمند بررسی بصری‌اند. محتوا و جریان سرور تست شده‌اند؛ صحت پیکسلی ادعا نمی‌شود.

اولویت بعدی: بررسی بصری موبایل و PNG، افزودن تصاویر با کلیدهای بالا، سپس گسترش متن قواعد با بازخورد واقعی. تعداد فکت‌ها و شروط حریم خصوصی با افزودن تصویر تغییر نمی‌کنند.
